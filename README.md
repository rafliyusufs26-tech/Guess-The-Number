# Guess The Number

My mini project in Python. So, in this project, you'll need to guess which number is right. 
It also has error handling. Whether you type random things in the input, it will give an error message
and tell you to write the right input.

### How does the script work?
Well... It's not much about it, you just run the code, and the first thing it says is "Do you wanna play the game?"
If you input 'y ', the game starts, and you guess the number. If you input a number too high, it will tell you the same thing, and if you input a number too low will tell you the same thing. When you finally guess the number, you win! (There's no losing,
I'll improve this next time)
